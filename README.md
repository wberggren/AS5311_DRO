This arduino sketch is for an arduino nano to display a length measurement
performed with an AS5311 sensor from the Osram company, Austria. The AS5311 sensor 
reads the displacement of a magnetic strip with a 2mm N/S pole pattern. 
North pole 1mm, south pole 1 mm; N+S = 2 mm. I bought the AS5311 sensor from 
Aliexpress for approximately 20 Euro. The strips can be bought from SIKO or 
Aliexpress. The strips are adhesive and can be glued to the moving part to be 
measured. The strips are normally supplied with a ss self adhesive protection 
strip for protection and easy cleaning. The advantage of these AS5211 sensors 
is that they are tiny 7x7x2 mm. This allows for a very compact sensor construction.
An 1.3 mm Oled is used to display the measurement. The only control is a reset 
button to zero the display. Power supply is 5V.
